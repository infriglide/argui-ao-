# argui-ao-
Um carro seguidor de linha com infravermelho é um robô autônomo que utiliza sensores ópticos para diferenciar a refletividade de uma linha escura sobre uma superfície clara. Com base nesses sinais, seu microcontrolador ajusta continuamente a rotação dos motores para manter o veículo exatamente sobre o trajeto demarcado.
